คำอธิบายผลลัพธ์

TP = ตรวจพบ Fraud ถูกต้อง · TN = ตรวจพบ Normal ถูกต้อง

FP = แจ้งเตือนธุรกรรมปกติผิด · FN = พลาดธุรกรรม Fraud

Precision = TP / (TP + FP)

Recall = TP / (TP + FN)

Total Cost = ยอดเงินของโกงที่หลุด (FN) + FP Cost × FP

โมเดลที่พร้อมใช้งาน

ตรวจสอบโมเดลที่ฝึกจาก Python และบันทึกไว้ในโฟลเดอร์ artifacts

หมายเหตุ: ตามสถาปัตยกรรม SafeSwipe การฝึกโมเดลทำแบบ Offline ด้วย Python หน้านี้ใช้ตรวจสอบสถานะโมเดลที่พร้อมให้ Backend โหลด ไม่ได้ฝึกโมเดลจริงใน Browser
Autoencoder ตัวอย่าง
เรียนรู้รูปแบบธุรกรรมปกติ แล้วใช้ Reconstruction Error เป็นคะแนนความผิดปกติ
ประเภท: UnsupervisedScore: Reconstruction Error
Logistic Regression ตัวอย่าง

ประเภท: SupervisedScore: Fraud Probability
Random Forest ตัวอย่าง

ประเภท: SupervisedScore: Fraud Probability
Isolation Forest ตัวอย่าง
แยกข้อมูลที่ผิดปกติออกจากข้อมูลส่วนใหญ่ด้วยการสุ่มแบ่งข้อมูล
ประเภท: UnsupervisedScore: Anomaly Score

OFFLINE: creditcard.csv → แบ่ง Train / Validation / Test → Preprocess → ฝึก Autoencoder, Logistic Regression, Random Forest, Isolation Forest → เลือก Threshold จาก Validation → บันทึก artifacts
ONLINE: Browser HTML → FastAPI → โหลด Preprocessor และโมเดลที่บันทึกไว้ → ทำนายคะแนน → คำนวณผลประเมินและต้นทุน → ส่งผลกลับ Dashboard

สูตรต้นทุน

ต้นทุนรวม = ยอดเงินของโกงที่หลุด (FN) + FP Cost × จำนวนแจ้งเตือนผิด (FP) · เงินที่ป้องกันได้สุทธิ = ยอดโกงทั้งหมด − ต้นทุนรวม · คำนวณที่ Backend ที่เดียว
